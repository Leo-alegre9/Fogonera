# Cuestionario al Cliente — Gallo Negro

Este documento reúne **todas las preguntas** que necesitamos responder junto con el cliente para poder especificar el sitio institucional, el catálogo de productos y el panel administrativo de Gallo Negro.

**Forma de trabajo:** el relevamiento se realiza en 8 bloques, de a uno por vez, esperando las respuestas del cliente antes de avanzar al siguiente. Cada pregunta tiene un identificador `PEN-XXX` que se cierra (pasa a `[CONFIRMADO]` y se traslada a `respuestas-cliente.md`) cuando el cliente responde. El estado vivo de cada pregunta se sigue en `preguntas-pendientes.md`.

Las preguntas de seguimiento que surjan de una respuesta (por ejemplo, si el cliente menciona marcas, categorías o productos concretos) se agregan como nuevos `PEN-XXX` a medida que aparecen, no están todas anticipadas aquí.

---

## Bloque 1 — Negocio y objetivos

| ID | Pregunta |
|---|---|
| PEN-001 | ¿Cuál es el nombre comercial definitivo con el que debe aparecer el sitio, y la razón social (si corresponde mostrarla)? |
| PEN-002 | ¿Cuál es la actividad principal de Gallo Negro y qué productos comercializa? |
| PEN-003 | ¿Quién es el público objetivo (a quién le vende: particulares, empresas, ambos; qué rubro)? |
| PEN-004 | ¿Dónde está ubicado el negocio y en qué zonas trabaja o entrega? |
| PEN-005 | ¿Cuáles son los datos de contacto actuales: teléfono, WhatsApp, correo electrónico, horarios de atención? |
| PEN-006 | ¿Qué redes sociales tiene Gallo Negro hoy y cuáles quiere mostrar en el sitio? |
| PEN-007 | Contanos brevemente la historia de Gallo Negro, su misión, sus valores y qué lo diferencia de la competencia. |
| PEN-008 | ¿Qué es lo que la marca quiere transmitir a quien visite el sitio? |
| PEN-009 | ¿Quiénes considera que son sus principales competidores? |
| PEN-010 | ¿Cuál es el **principa|l objetivo** de la página? (presentar la empresa, mostrar productos, generar consultas, generar contactos por WhatsApp, atraer clientes desde Google, o una combinación de estas) 
| PEN-011 | ¿Hay sitios web (de cualquier rubro) que le gusten como referencia de estilo o funcionamiento? |

## Bloque 3 — Sitio institucional

|---|---|

| PEN-021 | ¿Hay contenido institucional que NO quiere mostrar públicamente? |

## Bloque 4 — Catálogo de productos

| ID | Pregunta |
|---|---|
| PEN-022 | ¿Los productos se organizan en categorías? ¿Cuáles son (listado inicial)? ¿Hay subcategorías? |
| PEN-023 | ¿Un mismo producto puede pertenecer a más de una categoría? |
| PEN-024 | ¿Maneja distintas marcas de productos? ¿Cuáles? ¿Deberían poder usarse como filtro o tener una sección propia? |
| PEN-025 | ¿Necesita buscador de productos y/o filtros (por categoría, marca, u otro criterio)? |
| PEN-026 | ¿Los precios de los productos deben mostrarse públicamente, mostrarse como "Consultar precio", o no mostrarse en absoluto? |
| PEN-027 | ¿Habrá promociones o precios de oferta (con precio anterior tachado)? ¿Se ofrece financiación o pago en cuotas que deba mostrarse? |
| PEN-028 | ¿Necesita gestionar stock real (cantidad exacta), o alcanza con un estado simple (Disponible / Consultar disponibilidad / Sin stock), o no hace falta mostrar disponibilidad? |
| PEN-029 | ¿Habrá productos destacados y/o novedades en el catálogo? ¿Quién decide cuáles son? |
| PEN-030 | **Pregunta clave de alcance:** ¿el sitio debe solamente mostrar productos y permitir consultar (por ejemplo, por WhatsApp), o los clientes necesitan poder comprar y pagar directamente desde la web? |
| PEN-031 | ¿Cuántos productos tiene aproximadamente el catálogo inicial a publicar? |

| PEN-036 | ¿Los productos relacionados o similares deberían sugerirse automáticamente en la ficha del producto? |

## Notas de proceso

- Cada bloque se presenta al cliente por separado (entre 5 y 10 preguntas relevantes por vez), no el listado completo de una sola vez.
- Las respuestas se documentan en `01_Relevamiento/respuestas-cliente.md`, con su fecha y su impacto en requisitos.
- Las preguntas que surjan como consecuencia de una respuesta (seguimiento) se agregan a este documento con el siguiente `PEN-XXX` disponible y se anota de qué bloque/pregunta se originaron.
- El estado de avance (respondida / pendiente) se sigue en `01_Relevamiento/preguntas-pendientes.md`.
